# Phase 3 – Translunar Transfer and Lunar Capture

This phase models a full Earth–Moon transfer and lunar orbit insertion.

## Features
- Translunar injection (TLI)
- Moving Moon model
- Phase targeting
- Lunar gravity inclusion
- Lunar orbit insertion (LOI)
- Capture detection using orbital energy

## Key Result
A successful non-impacting lunar capture was achieved with tuned phase angle, delta-v, and LOI timing.
