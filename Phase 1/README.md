\# Phase 1 – Rocket Ascent Simulation



This phase models a simplified 1D vertical rocket ascent from the ground.



\## Features

\- Variable mass during burn

\- Constant thrust

\- Atmospheric drag using exponential density model

\- Gravity variation with altitude



\## Outputs

\- Altitude vs time

\- Velocity vs time

\- Acceleration vs time

\- Dynamic pressure and drag



\## Key Result

The model produces realistic ascent behaviour, including increasing acceleration due to mass loss and a peak in dynamic pressure during early flight.
